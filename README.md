# Dimensional Rift Prompt V7

用于生成“现实场景 + 手势控制的横向次元影像切片 + 局部异世界角色”的中英双语视频提示词。

## V7 的核心改动

V7 回滚掉容易被视频模型画成 UI、透明眼罩或取景框的后期制作术语，改用直接、可见的画面语言：

- 一块不透明、内部铺满异世界影像的宽横向切片；
- 直边、利角、极细青色—洋红色边缘缝，不是玻璃屏幕；
- 异世界角色使用完整的大尺寸头肩近景，五官与发型保持在同一张脸上；
- 异世界环境保留在角色脸部左右，不生成孤立眼睛或嘴唇；
- 切片从约 0.6 秒持续到约 10.0 秒，扫描光只在完整影像内部通过；
- 折叠只做浅幅弹性褶皱，不折成蝴蝶、菱形、书本或竖裂缝；
- 包含边缘光和折叠区域在内的完整视觉面积始终不超过画面 25%；
- 不规定视频比例，由用户在生成平台自行选择。

## 使用

提供时长、现实场景与人物、裂隙内场景与角色、艺术风格，以及可选收尾动作。技能输出可直接复制的英文提示词、中文执行版和自检结果。

验证提示词：

```bash
python scripts/validate_prompt.py prompt.md
```

验证器检查六段动作节拍、不透明影像填充、完整异世界大脸、现实场景稳定、持续可见时间、25% 面积上限、手势关系及常见失败项。
