# Dimensional Rift Prompt

用于生成“真人现实底片 + 小面积移动裂隙蒙版 + 局部异世界替换”的中英双语视频提示词。

## 当前核心机制

- 真人与现实场景作为不可改变的底片，每帧至少保留 75%。
- 裂隙完整视觉面积（含折面、溢光、模糊）严格不超过画面 25%。
- 异世界只替换裂隙当前覆盖到的身体与背景碎片；离开后立刻恢复现实。
- 整幅画面只有一个人、一个身体、一套同步动作。
- 强制禁止画中画、递归套娃、第二人物、全局异世界接管、HUD 屏幕、电子书和蝴蝶折页。

## 使用

提供：时长、现实场景、现实人物、异世界场景、异世界身份、艺术风格，以及可选收尾动作。

保存提示词后可运行：

```bash
python scripts/validate_prompt.py prompt.md
```

验证器会检查底片锁定、局部蒙版、双世界互斥、25% 面积上限、反画中画约束、手部遮挡关系和六段时间线。
