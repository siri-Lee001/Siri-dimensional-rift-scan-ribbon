# Dimensional Rift Scan Ribbon V8

生成“真人隔空操控无边界横向次元重绘带”的中英双语视频提示词。

V8 根据连续测试视频重构了底层模型：裂隙不再是带边框、内部放置异世界头像和独立背景的显示屏，而是贴合现实构图的局部异世界化区域。它经过人物哪个身体部位，就只替换对应部位；切片上下的人物轮廓保持连续。

主要改进：

- 去除发光边框、白框、玻璃和屏幕感；
- 禁止完整头像随切片移动及脸部自动铺满；
- 双手永久位于切片两端之外，不能穿过或遮挡影像；
- 5 秒脚本采用复杂度预算，折叠版只保留打开、上扫、折叠复原、回扫、关闭；
- 折叠被提升为独立主动作：形成一个相连的蝴蝶结形空间折面，短暂停留后完全展平；
- 5/10/15/30 秒按时长增加动作，不把全部特效塞进短片；
- 视觉面积始终不超过画面 25%，不规定视频比例。

运行验证：

```bash
python scripts/validate_prompt.py prompt.txt
```
