# Dimensional Rift Scan Ribbon

为本地 AI Agent 生成横向无边框次元影像切口视频提示词。

## 当前底层模型

- 裂隙是一条现实被另一重现实直接替换的狭长区域，不是可见物体。
- 异世界影像铺满到裂隙边缘，没有玻璃留白、框体、屏幕和HUD装饰。
- 边界只允许一像素青—洋红色差缝，不使用霓虹外框和放射光线。
- 折叠只使用一道偏心斜折痕，形成两个不等大的连接平面；禁止对称V形、蝴蝶和展开电子书。
- 裂隙内只出现一个与真人同尺度的替代脸部与上半身切片，禁止机库远处小人和多个机甲。
- 双手与裂隙保持空气间隔，一只手从前方掠过、另一只手留在后方，禁止双手抓住对称角点。
- 不指定输出比例，由用户在生成平台自行选择。

## 面积双保险

- 完整视觉包络必须限制在宽≤78%、高≤22%的横向包围盒内。
- 包络包括影像、色差缝、溢色、尖角、形变、运动模糊和所有折叠面。
- 所有折叠面投影面积相加后仍≤完整画面25%。
- 主切口建议约宽74%、高18%，填充面积约13.32%，为边缘和运动保留余量。

## 验证

```powershell
python scripts\validate_prompt.py --self-test
python scripts\validate_prompt.py path\to\prompt.md
```

校验器会拦截HUD、透明显示器、电子书、蝴蝶、对称折叠、霓虹放射线、迷你人物、双手抓屏幕以及面积超限。
