# Dimensional Rift Scan Ribbon

为本地 AI Agent 提供几何次元裂隙视频提示词。当前版本将裂隙定义为“锐边霓虹能量轮廓＋绷紧半透明全息膜”，不再使用容易生成黑布的 ribbon、dark slit 和柔软手风琴语义。

## 核心规则

- 裂隙拥有笔直边缘、锐角、窄幅青—洋红—紫色线性能量轮廓。
- 内部是一层平整、光滑、绷紧、半透明的全息影像膜。
- 折叠由硬直折痕和锐角三角面构成，不产生布料褶皱、下垂或黑色背面。
- 双手位于裂隙左右或顶部两角，通过无形张力隔空操控，绝不从下方托举。
- 裂隙中的另一身份实时镜像真人的脸、视线、表情、姿势和手势。
- 11秒使用6个连续动作：能量线激活、展开、景深错切、硬折叠、重开扫描、闭合。
- 不指定视频比例，由用户在生成平台自行选择。

## 25%面积硬上限

每一帧中，所有裂隙可见面的屏幕投影面积总和不得超过完整画面的25%。折叠或分裂不会给每块面片单独增加25%额度；所有面片必须相加计算。

示例安全尺寸：画面宽度约78% × 高度约28% = 21.84%画面面积。

## 质量验证

```powershell
python scripts\validate_prompt.py --self-test
python scripts\validate_prompt.py path\to\prompt.md
```

校验器检查6段时间轴、全息膜材质、能量边缘、25%面积规则、折叠面面积求和、双手位置、替代身份同步，以及黑布、丝带、纸片、卡片、胶片和软褶皱禁项。
