# Duration and Complexity Budget

## General rules

- Start motion at 0.00 seconds.
- Use 0.20–0.35 second readable settles, never dead holds.
- Close only in the final 10–15%.
- One beat carries one main ribbon verb.
- Every beat changes hand trajectory or finger state.

| Duration | Beats | Maximum effect verbs | Recommended grammar |
|---|---:|---:|---|
| 4–6s | exactly 5 | 4 | open + scan + one hero interaction + return/sweep + close |
| 7–10s | 6–8 | 6 | open + vertical scan + interaction + lateral travel + recovery + close |
| 11–15s | 8–11 | 8 | two-axis scans + 2–3 interactions + recoveries + close |
| 16–30s | 12–20 | 12 | three-act performance with separated advanced beats |

## Five-second fold profile

Use exactly:

1. **0.00–0.60** — F1 chest open.
2. **0.60–1.55** — S1 registered rise to face.
3. **1.55–2.75** — G1 fold, short hold, complete flattening. No travel.
4. **2.75–4.30** — S2 return to chest. If the user prioritizes lateral motion over scanning, substitute one S3 sweep, not both.
5. **4.30–5.00** — F2 close.

Do not add scan light, glow burst, extra tilt, diagonal travel, pulse, multiple expression turns, or ending gesture to this profile.

## Longer durations

- At 7–10 seconds, add one lateral sweep after a full flattening recovery.
- At 11–15 seconds, add P1 or P2 and a second expression turn; keep G1 isolated.
- At 16–30 seconds, vary vertical, lateral, and diagonal paths across acts; allow at most two high-risk units, each followed by a flat recovery.
